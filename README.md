# WispJolt

WispJolt enables real-time, distributed data processing and auto-scaling across a microservices-based platform utilizing multiple processor cores.

With WispJolt, you get a lightweight tool that stays out of your way.

**What you get**

- WispJolt enables real-time, distributed data
- processing and auto-scaling across a
- microservices-based platform utilizing multiple processor

- python

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/WispJolt.git`
2. `cd WispJolt`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
